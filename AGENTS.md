# Project rules

- Create upcoming Wh0 session pages with the existing show generator and wire their feed entry, adjacent-session navigation, route, and sitemap together so each page is discoverable.
- Keep provided Wh0 cue timestamps in the page tracklist and mirror ordered artists/titles in `show_tracks` so the website and tracklist consumers agree.
- Create Future Dance Anthems pages with the existing generator, register their route, sitemap and dedicated-page feed lookup, and keep playback disabled until the official RSS audio exists; this preserves one permanent page per episode without guessed audio links.
- Keep the consent design preview presentation-only and reuse the Google CMP CSS classes; this lets layouts be reviewed without storing real choices or replacing the certified CMP.
- Initialize OpenAI measurement through the existing advertising consent adapter, deny unknown/GPC/CMP-refused choices, load nothing from OpenAI until Google's CMP has answered or is known not to apply (`gdprApplies: false`, ad script failed, or — in Lovable preview only — a grace period elapsed), and disclose account-controlled matching in the consent notice; preserve existing pixel settings and never manually add customer identifiers to live-start events.
- Emit live-start conversions only inside the shared audio `playing` handler using a consumed user-intent marker; recovery events and unavailable pixels must never alter playback or replay old conversions.
